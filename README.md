# Volcano: Feature & Process — Interactive Demo

This is a small static interactive demo showing how subduction and mantle melting produce volcanoes.

Open `index.html` in a browser to view the demo. Use the slider to change melting intensity and the "Erupt" button to animate lava flow.

Files:

- [index.html](index.html) — main page with interactive SVG
- [styles.css](styles.css) — styling and animation rules
- [script.js](script.js) — controls and interactivity

New: The site now includes a second scene demonstrating river meandering and erosion.
- Use the scene selector in the controls to switch between `Volcano` and `River`.
- For `River`, adjust `Erosion intensity` and click `Simulate` to see channel migration effects.

Try it locally:

```bash
# from project folder
open index.html
```

- This static site is intentionally small and designed for illustration and classroom use.
