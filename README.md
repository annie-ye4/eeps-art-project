# Volcano: Feature & Process — Interactive Demo

This is a small static interactive demo showing how subduction and mantle melting produce volcanoes.

The focus is a volcanic mountain created by subduction-driven mantle melting. I show that connection by letting the magma chamber grow, the cone erupt, and the lava flow when melting increases. A second river scene adds a contrast example, where erosion and deposition slowly carve a meandering channel so the site can show more than one geologic process shaping Earth’s surface.

Use the slider to change melting intensity and the "Erupt" button to animate lava flow.

Files:

- [index.html](index.html) — main page with interactive SVG
- [styles.css](styles.css) — styling and animation rules
- [script.js](script.js) — controls and interactivity

The site includes a second scene demonstrating river meandering and erosion.
- Use the scene selector in the controls to switch between `Volcano` and `River`.
- For `River`, adjust `Erosion intensity` and click `Simulate` to see channel migration effects.
